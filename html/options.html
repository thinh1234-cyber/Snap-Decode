Client-Side Pure JS Engine (Mặc định)

Giải mã mã QR tức thì qua Canvas & Web API ngay trong trình duyệt. Hoạt động 100% offline, không bắt buộc cài đặt hay chạy backend Python.

Sẵn sàng • In-Browser
Cơ chế xử lý: HTML5 Canvas + Pure JS Engine
Phụ thuộc máy chủ: 0 (Hoàn toàn độc lập)
Tốc độ giải mã: ~5ms - 15ms / frame (Tức thì)
Tiêu thụ tài nguyên: < 2MB RAM (Cực kỳ nhẹ)

Engine Giải Mã (Client-side)

Tiện ích hoạt động 100% nội bộ trong trình duyệt, không cần cài đặt backend hay phần mềm ngoài.

100% Offline
In-Browser JS Engine (Sẵn sàng) Cơ chế: 6-Pass Progressive Pipeline • Tự động giải mã siêu tốc
Bộ giải mã: jsQR + 6-Pass Preprocessors
Môi trường: Chromium Sandbox (100% Client-side)
Bảo mật dữ liệu: Tuyệt đối không gửi ảnh ra ngoài
Tiêu thụ rảnh rỗi: 0% CPU • 0% RAM
